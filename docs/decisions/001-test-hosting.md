# 001. 2개월 테스트 서비스의 호스팅

## 상황

서버 운영 초보자가 프론트와 API를 먼저 공개 테스트하고, 추후 분석 기능을 추가한다.
GPT 사용량은 별도 제공되며 현재 배포에는 PostgreSQL과 Celery 실행을 포함하지 않는다.

## 결정

프론트는 Vercel에 유지하고 API와 Redis는 Render Singapore에 둔다.
무료 플랜에서 먼저 검증하고 상시 가동이 필요할 때 사용자 승인으로 유료 전환한다.
실제 서비스의 소스 브랜치는 main이다. 변경은 Issue 작업 브랜치 → dev → main PR을 따른다.

## 대안과 이유

AWS Lightsail은 신규 크레딧으로 현금 지출을 줄일 수 있으나 서버 패치, HTTPS,
백업과 장애 복구를 직접 관리해야 한다. 2개월 서비스 완성이 목적이므로 운영 부담이
적은 Render를 선택했다. AWS 리소스 생성은 이 결정에 포함하지 않는다.

## 한계와 재검토 조건

무료 API의 유휴 정지, Redis 휘발성, 512MB 메모리는 테스트 제약이다.
현재 쿠키 정책을 유지하기 위해 Vercel /api 프록시를 별도 프론트 PR로 연결하고
Origin·쿠키·클라이언트 IP를 실배포에서 검증한다. 검증 전 공개 운영 완료로 보지 않는다.
분석 워커/DB 도입, 메모리 부족, 동시 분석 증가 또는 장기 운영 시 사양과 예산을 다시 정한다.
