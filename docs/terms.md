## 현재 프로젝트를 읽는 데 필요한 용어

| 용어 | 이 프로젝트에서의 의미 |
| :--- | :--- |
| PoC | 제품의 전체 연결이 실제로 동작하는지 확인하는 개념 검증. 임상 유효성 검증이 아님 |
| Agent | 분야별 도구 결과·근거를 해석하고 정해진 출력 계약으로 반환하는 담당 구성요소 |
| Tool / provider | 실제 예측 모델 또는 외부 자료 조회를 수행하는 구현 |
| Orchestration / DAG | 단계의 의존성·순서·실패·중복 실행을 관리하는 흐름 제어 |
| Tractability | 특정 약물 형태로 표적에 접근할 수 있다는 근거. 질환 연관성 점수와 별개 |
| Causal support | 질환과 표적의 인과성을 지지하는 근거의 평가. 임상 효과 확정이 아님 |
| ADMET | 흡수·분포·대사·배설·독성 관련 모델 예측과 그 해석 |
| DTA | 약물–표적 결합 친화도 예측. 결합이 억제·활성화·약효를 직접 증명하지 않음 |
| Artifact / output JSON | 특정 실행의 결과·근거·버전·오류·사용량을 보존한 기록 |
| Projection / DTO | 내부 저장 기록에서 화면에 공개할 필드만 추린 응답 |
| Replay / continuation | 명시적으로 지정한 과거 결과를 재사용하거나 일부 단계만 새로 실행하는 개발 경로 |
| Cache | 같은 입력 요청의 결과를 자동 재사용하는 기능. 현재 일반 분석에는 없음 |
| partial_failure | 실행 가능한 결과를 보존하면서 일부 단계 또는 해석 실패를 표시한 상태 |
| conditional_go | 추가 검증을 조건으로 한 연구 우선순위 판단. 치료 권고·임상 승인이 아님 |

처음 읽는 순서는 [프로젝트 현황](project-status.md)의 시스템 지도를 참고한다.
