# EviDrug

EviDrug는 초기 신약 후보를 둘러싼 분산되고 상충하는 근거를 검토해 다음 단계 진행 여부와
우선 검증할 항목을 제시하는 멀티에이전트 의사결정 지원 시스템입니다.

표적 타당성, 결합 가능성, ADMET 근거를 하나의 분석 흐름으로 연결하면서 출처와 한계를
보존합니다. 단순히 후보에 점수를 매기는 대신, 제한된 실험 자원을 어디에 먼저 사용할지
판단할 수 있는 근거를 제공하는 것이 목표입니다.

## 무엇을 제공하나요?

- 질환과 후보 물질을 바탕으로 분석 대상을 구성합니다.
- 표적의 질환 연관성과 인과 근거를 검토합니다.
- 후보 물질의 표적 결합 가능성과 ADMET 위험을 함께 평가합니다.
- 각 전문 분석의 근거와 한계를 종합해 진행 판단과 다음 검증 단계를 제안합니다.
- 분석 과정과 결과를 저장해 다시 확인할 수 있습니다.

## 분석 흐름

```text
질환·후보 입력
      ↓
표적 탐색 및 우선순위화
      ↓
결합 가능성·ADMET 분석
      ↓
근거 종합 및 의사결정
      ↓
우선 검증 항목 제안
```

EviDrug의 결과는 연구자의 결정을 대체하지 않습니다. 현재 확보된 근거와 불확실성을
구조화해 다음 실험과 검토의 우선순위를 정하는 데 사용합니다.

## 프로젝트 현황

전체 분석 실행과 저장 결과 재열기까지 연결되어 있으며, 현재는 의사결정 품질과 반복
안정성을 검증하고 있습니다. 단일 실행의 성공과 과학적 정확도 검증은 구분합니다.

구현 범위, 검증된 내용과 남은 한계는
[프로젝트 상태](docs/project-status.md)에서 확인할 수 있습니다.
