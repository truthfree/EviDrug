# 질환 자동완성과 후보 확인

인증된 사용자가 영어 질환명 또는 표현형을 입력하고 Open Targets의 표준 후보 중 하나를
명시적으로 확인하는 UI다. 이 기능은 OpenAI 모델을 호출하지 않는다.

## 주요 구성요소

- `api.ts`: 질환 검색 HTTP 요청, 응답 구조 검증과 오류 코드 변환
- `useDiseaseSearch.ts`: 350ms debounce, 요청 취소와 사용자용 상태 관리
- `DiseaseSearchPanel.tsx`: combobox, 후보 목록, 선택과 확인 UI
- `DiseaseSearchPanel.css`: 작업공간 안의 입력, 후보와 상태 표현

## 사용자 흐름

1. 두 글자 이상의 영어 질환명 또는 표현형을 입력한다.
2. 입력이 350ms 동안 멈추면 `/api/v1/diseases/search`를 호출한다.
3. “이 질환을 찾으신 건가요?” 목록에서 표준명과 EFO/MONDO ID를 확인한다.
4. 후보를 선택한 뒤 `선택한 질환으로 계속`을 눌러 명시적으로 확인한다.
5. 입력을 변경하면 기존 선택과 확인 상태는 즉시 해제된다.

후보는 마우스뿐 아니라 위·아래 방향키와 Enter로 선택할 수 있다. relevance score는
검색 순위 계산에 사용되지만 사용자가 확률이나 신뢰도로 오해하지 않도록 화면에는
표시하지 않는다.
